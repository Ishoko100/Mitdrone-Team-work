# MITDRONE

Frontend-only drone marketplace monorepo. Mocked with MSW, ready for backend integration.

| App | Path | Port |
| --- | --- | --- |
| Marketplace | `apps/marketplace-web` | 3000 |
| Vendor dashboard | `apps/vendor-dashboard` | 3001 |
| Admin dashboard | `apps/admin-dashboard` | 3002 |

```bash
nvm use        # Node 20
npm install
npm run dev
```

> Phase 0 scaffold. Full README (endpoint table, backend handoff) is delivered in Phase 5.
